# Test set and quality checks

Use real course material, not toy examples. Keep private files out of Git (store in a local `test-data/` folder that is git-ignored) and list them here by name only.

## Files to collect (aim for one course first)
- [ ] 2-3 lecture files (at least one slide deck, one text-heavy PDF)
- [ ] 1 past quiz
- [ ] 1 assignment
- [ ] 1 past paper
- [ ] The CLO table, both as a screenshot and as pasted text
- [ ] A short pasted "important topics" note
- [ ] 1 textbook chapter (optional)
- [ ] Phase 2: 2-3 photos or scans of real handwritten notes

## Checks
For each, record pass/fail and notes in docs/progress.md.

| # | Check | Expected |
|---|---|---|
| 1 | Upload and extraction | Text appears for every page; image-only pages flagged |
| 2 | Chunking | No chunk cuts a sentence or formula badly; page numbers correct |
| 3 | Question with answer in notes | Correct answer with a correct citation |
| 4 | Question NOT in notes | "Not found in your materials" |
| 5 | CLO extraction (image and text) | All CLOs found with correct PLO and weightage, none invented, unclear words flagged |
| 6 | Topic extraction | Topics match what you'd list yourself (aim for 80%+ overlap) |
| 7 | Topic ranking | Topics from past papers and quizzes, and from high-weightage CLOs, appear near the top |
| 8 | Generated quiz | Each question is clear, answerable from the source, and cited |
| 9 | Grading | Right answers pass, wrong answers fail, feedback cites source |
| 10 | Privacy | A second test user cannot see the first user's files |
| 11 | Teach then quiz | Each topic shows an explanation first, then questions, all cited |
| 12 | Handwritten notes (Phase 2) | Text is readable, misreads can be corrected, low-confidence pages flagged |
